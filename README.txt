SIMPUS Nusantara - landing page

Struktur:
  index.html         halaman utama
  css/style.css      seluruh tampilan
  js/main.js         animasi peta, tab layar aplikasi, formulir
  assets/logo.png    logo resmi Simpus Nusantara
  assets/favicon.svg ikon tab browser

Cara pasang: unggah seluruh isi folder ini ke hosting (folder public_html atau root domain).

Nomor WhatsApp: buka js/main.js, isi baris  var WA = '';  dengan nomor format 62..., contoh var WA = '6281234567890';
Foto: simpan di folder assets/, lalu pasang dengan <img src="assets/nama-file.jpg" alt="...">.
