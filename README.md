# SIMPUS Nusantara · Satu SIMPUS untuk Seluruh Indonesia

Landing page resmi untuk **SIMPUS Nusantara** oleh KLIKMEDIS · PT Mitra Bestari Teknologi.

## 🌟 Fitur Unggulan
- **Transformasi 4 Kluster ILP Kemenkes RI:** Manajemen, Ibu & Anak, Usia Dewasa & Lansia, serta Penanggulangan Penyakit Menular.
- **Dashboard Monitoring Eksekutif Dinkes:** Pemantauan capaian SPM, SKDR, dan log bridging seluruh puskesmas secara real-time.
- **Bridging BPJS PCare & Mobile JKN:** Antrean online, validasi kepesertaan NIK instan, dan klaim tanpa double-entry.
- **SATUSEHAT Kemenkes RI (Permenkes No. 24/2022):** Standar variabel data FHIR Encounter, Condition, Observation, Procedure, dan Medication.
- **100% Tangguh Offline:** Pelayanan posyandu dan puskesmas keliling (pusling) di daerah terpencil tetap berjalan normal tanpa internet.
- **Jejaring Berbagi Praktik Baik:** Forum sharing antar-Dinas Kesehatan dan studi kasus sukses puskesmas dalam menjalankan kepatuhan regulasi ILP dan SPBE di lapangan.
- **Model Tata Kelola Gotong Royong:** Voting prioritas fitur tiap 3 bulan, pendampingan implementasi tuntas, dan jaminan *Software Escrow*.
